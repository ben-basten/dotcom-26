# dotcom-26

A blog page built in Astro, using static markdown as a git-based CMS.

## Command line

- Always use the `pnpm` package manager to run commands
- `pnpm typecheck` to check for any type errors in the codebase
- `pnpm lint` to run ESLint across the codebase

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
